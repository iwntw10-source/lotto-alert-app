## 먼저 알아둘 사실 (설문의 근거)

| 항목 | 실제 동작 |
|---|---|
| 계정 | **없음** (회원가입·로그인 없음) → 계정 삭제 URL 불필요 |
| 등록한 복권 번호/회차 | **기기 안에만 저장**. 운영자 서버로 전송 안 됨 (운영 서버 자체가 없음) |
| 복권 사진 | 촬영은 Google 코드 스캐너, 갤러리는 시스템 사진 선택기. 기기 안에서 QR만 읽고 **저장·전송 안 함** |
| 권한 (최종 매니페스트 기준) | `INTERNET`, `POST_NOTIFICATIONS`, `ACCESS_NETWORK_STATE`, `WAKE_LOCK`, `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE`(라이브러리 선언, 실제 미사용), 광고 관련 `AD_ID`/`ACCESS_ADSERVICES_*` |
| 카메라·사진첩·위치 권한 | **없음** (카메라는 Google 스캐너가 처리, 사진은 시스템 선택기) |
| 외부 통신 | 동행복권 당첨번호 조회(실패 시 GitHub Pages 공개 데이터), AdMob. 모두 HTTPS |
| 광고 | AdMob 하단 배너 |
| 알림 | 로컬 알림 + 앱 내 예약 작업. 푸시 서버(FCM) 미사용 |

## 1. 데이터 보안 (Data safety)

### 1단계 · 개요

| 질문 | 답 | 근거 |
|---|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | 광고 SDK(AdMob)가 수집 |
| 전송 중 암호화되나요? | **예** | 모든 통신 HTTPS |
| 계정 생성 방법 | 해당 없음 (계정 없음) | |
| 삭제 요청 | ⚠️ 화면 문구에 맞춰 선택 — 앱 자체 데이터는 앱 삭제/✕ 버튼으로 삭제 가능, 광고 ID는 기기 설정에서 삭제 가능. 계정이 없어 **삭제 요청 URL은 필요 없음** | |
| 추가 배지 (독립 보안 검토 / UPI) | **체크 안 함** | 증빙 없이 표시하면 정지 위험 |

### 2단계 · 데이터 유형 (AdMob 몫)

이 앱이 직접 수집하는 사용자 데이터는 **없습니다.** 아래는 **Google Mobile Ads SDK가 수집하는 항목**입니다.

⚠️ AdMob 공식 안내 페이지("Google Mobile Ads SDK 사용 시 Play 데이터 보안 섹션 작성 방법")의 표와 **반드시 대조**해서 체크하세요. 보통 다음과 같습니다.

| 카테고리 | 항목 | 수집 | 공유 | 목적 |
|---|---|---|---|---|
| 기기 또는 기타 ID | 기기 또는 기타 ID (광고 ID) | 예 | 예 (Google) | 광고 또는 마케팅, 사기 방지·보안 |
| 앱 활동 | 앱 상호작용 | 예 | 예 | 광고 또는 마케팅, 분석 |
| 앱 정보 및 성능 | 비정상 종료 로그 / 진단 / 기타 성능 데이터 | 예 | 예 | 분석 |
| 위치 | 대략적인 위치 (IP 기반) | 예 | 예 | 광고 또는 마케팅 |

체크하지 **않는** 것: 이름·이메일·전화번호·주소, 정확한 위치, 사진·동영상, 연락처, 건강·금융 정보, 메시지 등 전부.
(복권 번호와 사진은 기기 안에서만 처리되며 앱 밖으로 나가지 않으므로 "수집"에 해당하지 않습니다.)

## 2. 광고

## 3. 콘텐츠 등급 설문

- 이메일: 본인 이메일
- 카테고리: **유틸리티, 생산성, 커뮤니케이션 또는 기타**
- 폭력·성적 콘텐츠·욕설·통제 물질·사용자 간 상호작용·위치 공유·디지털 구매: 전부 **아니요**
- **도박 관련 문항** ⚠️: 이 앱은 복권을 판매하거나 베팅을 제공하지 않습니다(당첨 확인 도구). 사실대로 "실제 돈을 거는 도박/시뮬레이션 도박 없음"으로 답하되,
  복권 *참조* 문항이 따로 나오면 사실대로 답변하세요. 등급이 높게 나와도 타겟이 성인이므로 문제 없습니다. 답변을 임의로 낮추면 나중에 앱이 정지될 수 있습니다.

## 6. 스토어 등록정보 초안

### 간단한 설명 (80자 이내)
```
복권 QR을 촬영하거나 사진으로 등록하면 추첨 후 당첨 결과를 알림으로 알려드려요.
```

### 자세한 설명
```
※ 이 앱은 동행복권과 무관한 비공식 앱입니다. 복권을 판매하거나 구매를 중개하지 않습니다.

복권을 사고 사진만 찍어 두세요. 추첨이 끝나면 당첨 결과를 알림으로 알려드려요.

■ 이렇게 간단해요
1. 앱을 열고 [복권 등록]을 눌러요
2. 복권의 QR코드를 촬영하거나, 갤러리 사진을 골라요 (여러 장도 OK)
3. 추첨 날 저녁, 당첨 여부가 알림으로 도착해요

■ 주요 기능
• QR 촬영 / 갤러리 등록 — 번호를 직접 입력할 필요 없이 자동으로 읽어요
• 추첨 후 자동 확인 — 앱을 켜 두지 않아도 알림으로 결과를 알려드려요
• 지난 회차 조회 — 화살표로 회차를 넘기며 당첨번호와 내 복권을 확인해요
• QR이 안 읽히면 번호를 직접 입력할 수 있어요
• 등록한 복권 정보는 내 휴대폰에만 저장돼요

■ 안내
• 로또 6/45를 지원합니다.
• 앱에 표시되는 결과는 참고용입니다. 최종 당첨 확인과 당첨금 수령은 동행복권 공식 결과와 절차를 따라 주세요.
• 만 19세 이상 이용 가능합니다.
```

> 이름·설명에 "동행복권" 로고나 공식 서비스로 오해할 표현을 쓰지 마세요 (사칭 정책). 위 초안은 **비공식 앱**임을 첫 줄에 밝혔습니다.
